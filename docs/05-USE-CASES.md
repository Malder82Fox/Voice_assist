# 05. Каталог пользовательских сценариев (VISION)

Примеры команд для формирования будущего бэклога. **В текущем проекте они не реализованы.**

## Локальные команды — возможный MVP

| Команда пользователя | Ожидаемое поведение |
|---|---|
| «Который час?» | Указать локальное время и часовой пояс при необходимости |
| «Какое сегодня число?» | Дата на русском |
| «Что ты умеешь?» | Справка по реально активным навыкам |
| «Повтори ответ» | Повторить последний ответ текущей сессии |
| «Стоп» | Прекратить озвучивание; остановку capture — отдельный control |
| «Я тебя не понял» | Повторить короче/переключиться на текст |
| «Какие модули доступны без интернета?» | Сообщить о локальных возможностях |

## Персональный/desktop помощник — после MVP

| Запрос | Внешний эффект / требование |
|---|---|
| «Напомни завтра проверить письмо» | Создание напоминания, подтверждение времени и зоны |
| «Какое у меня следующее совещание?» | Авторизованный календарь, read-only |
| «Открой AutoCAD» | Только явно разрешённый список программ |
| «Покажи мои задачи на неделю» | Авторизованный task provider |
| «Напиши сообщение коллеге» | Сначала выбрать адресата и показать текст, затем подтвердить отправку |
| «Какая погода в Душанбе?» | Внешний источник, время прогноза |
| «Включи музыку» | Конфигурируемый и отключаемый media plugin |

## CanLine OS — первый пилот ТОЛЬКО чтение

| Голосовой запрос | Модуль-источник | Тип ответа |
|---|---|---|
| «Какой OEE на линии за текущую смену?» | MES | Значение, период, источник |
| «Почему вчера остановился Bodymaker 3?» | MES downtime events | Причины, время, неопределённость |
| «Какова скорость Cupper 1 сейчас?» | SCADA / historian API | Значение + timestamp + stale status |
| «Есть ли критические аварийные сообщения?» | SCADA read API | Список + дата обновления |
| «Какие открытые заявки на ремонт?» | Maintenance/MWS | Заявки в рамках permissions |
| «Есть ли незакрытые отклонения качества?» | QMS | Статусы, не технический вердикт |
| «Когда придёт запчасть для Neckera?» | ERP procurement | Заказ/ETA из системы, если известен |
| «Что назначено на мою смену?» | Task & Workflow / HR | Ограниченный задачами пользователя ответ |
| «Покажи топ-5 потерь производительности» | MES / analytics | Период, метрика, метод расчёта |
| «Сравни две предыдущие смены» | MES | Корректно нормированные показатели |

Система уточняет площадку, линию, объект или период, когда неоднозначность существенно влияет на результат.

## Запрещённый для ранних этапов класс команд

«Запусти Bodymaker», «отключи защиту», «сбрось PLC alarm», «измени скорость Neckera», «открой клапан», «сними блокировку»: **нет инструментов для выполнения таких команд**. Ответ должен объяснять, что голосовое управление процессом недоступно. Даже подтверждение голосом **не является достаточной защитой**.

## Требования к правдоподобию

Для каждого ответа на основе CanLine OS показывать: площадку/линию, источник, временное окно, timestamp фактических данных и, при необходимости, «данные устарели». Не придумывать OEE, количество банок, причины остановки или финансовые цифры.

См. [интеграцию](06-CANLINE-OS-INTEGRATION.md) и [безопасность](07-SECURITY-PRIVACY.md).
