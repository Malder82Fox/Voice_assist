# Voice Assist — идея будущего голосового ассистента

> **Статус: CONCEPT / DOCUMENTATION ONLY (11.10.2026).**
> Здесь хранится проектное видение и требования на будущее. Текущая ветка \`main\` **не содержит работающего приложения**. Разработка, модернизация и интеграции **не начаты**.

## Зачем существует проект

Создать **независимое, расширяемое ядро голосового взаимодействия**: пользователь разговаривает с компьютером или информационной системой естественным языком, а она распознаёт запрос, проверяет права, получает данные или выполняет разрешённое действие и отвечает голосом/текстом.

Два перспективных сценария:
1. **Personal/Desktop Assistant:** русскоязычный помощник для Windows/ПК (время, задачи, напоминания, справки, календарь, приложения, интеграции).
2. **CanLine OS Voice Interface:** дополнительный интерфейс к промышленной платформе SCADA + MES + ERP + MWS + QMS. Первая промышленная версия — **только чтение**, без управления PLC, технологическим процессом или средствами безопасности.

Потенциальные дополнительные применения: smart home, информационные киоски, мобильные клиенты. Это идеи, не обязательства по реализации.

## Где старый проект?

- \`main\`: концепция и документация; **не содержит старого кода**.
- \`master\`: **исторический прототип 2022 года**, Python с SpeechRecognition, pyttsx3 и онлайн-интеграциями. Сохранён как источник для анализа, **не рекомендуется к запуску без ревизии безопасности**.
- **Не сливать \`master\` целиком в \`main\`**: исторический репозиторий содержит \`env/\`, IDE-файлы и следы учетных данных.

## Принципы на будущее

- Независимость от CanLine OS; интеграция только через разрешённые API.
- Модульность: STT, понимание намерения, маршрутизация, навыки, TTS — заменяемые компоненты.
- **Offline-first как цель**: базовые команды на локальном устройстве, сеть для явно подключённых сервисов.
- Разрешения по умолчанию закрыты; никакого произвольного выполнения команд ОС.
- Различать речь, намерение, разрешённое действие и фактический результат.
- Локализация: сначала русский; далее другие языки по необходимости.
- Открытая документация без токенов, паролей и персональных данных.
